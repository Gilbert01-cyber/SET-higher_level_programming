# 0x15. JavaScript - Web interactive

Vanilla JavaScript scripts that select and change elements on a web page and react to user clicks. No external library is used.

## Tasks

- 0-script.js: turns the header text red (#FF0000)
- 1-script.js: turns every p element blue (#0000FF) using querySelectorAll
- 2-script.js: turns the header red when DIV#red_header is clicked
- 3-script.js: adds the class red to the header on click using classList.add()
- 4-script.js: toggles the header class between red and green using classList.toggle()
- 5-script.js: adds a li element with the text Item to UL.my_list on click
- 6-script.js: changes the header text to New Header!!! on click using textContent
